# NovaTech Solutions

## Over het project

Dit project is een demo-website voor het fictieve bedrijf
NovaTech Solutions.

Het bedrijf helpt ondernemers met moderne websites,
digitale oplossingen en professionele online ervaringen.

## Pagina's

- index.html - Homepage en introductie.
- about.html - Informatie over het bedrijf.
- contact.html - Contactgegevens.

## Styling

De website gebruikt een apart CSS-bestand:

## Website openen

1. Download of clone de repository.
2. Open de projectmap.
3. Dubbelklik op index.html.
4. De website opent in je browser.
